# Miles Automobile 

**Luxury & Quality Automobiles**

Miles Automobile is a modern, responsive automobile dealership website designed to showcase luxury and quality vehicles to customers in Abuja, Nigeria, and across the country. The website provides an interactive showroom experience where visitors can explore vehicles, compare specifications, filter inventory, and contact the dealership for enquiries and purchases.

## Overview

The website features a premium automotive design with a black, white, and red colour palette, interactive vehicle displays, and an intuitive browsing experience across desktop and mobile devices.

It showcases foreign-used, Nigerian-used, and brand-new vehicles from popular automobile manufacturers, including Mercedes-Benz, BMW, Honda, BYD, and Toyota.

## Features

- **Interactive Vehicle Showcase:** Explore featured vehicles through a dynamic showroom with vehicle navigation and specifications.
- **Vehicle Inventory:** Browse available vehicle listings with prices, model years, conditions, and technical details.
- **Search and Filtering:** Narrow down vehicle options using available inventory filters.
- **Brand and Model Selection:** Explore vehicles by manufacturer and model.
- **Vehicle Details:** View detailed specifications, vehicle information, and interactive detail panels.
- **Vehicle Inspection and Verification Information:** Discover dealership services, including vehicle inspection and document verification.
- **Direct Customer Enquiries:** Contact the dealership through WhatsApp and other available contact channels.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile screens.
- **Interactive Animations:** Smooth transitions, animated vehicle displays, and interactive interface elements.
- **Dealership Information:** Access business contact details, location information, and social media links.
- **Search Engine and Social Sharing Metadata:** Includes page descriptions and Open Graph metadata to support discoverability and link previews.

##Technologies Used

- **HTML5** — Website structure and semantic markup.
- **CSS3** — Responsive layouts, custom styling, animations, and visual effects.
- **JavaScript** — Interactive components, vehicle navigation, inventory filtering, and user interface behaviour.
- **Google Fonts** — Archivo, Instrument Sans, and IBM Plex Mono typography.
- **SVG** — Scalable interface icons.
- **Google Maps linking** — Provides access to directions to the dealership.
- **WhatsApp integration** — Supports direct customer enquiries.

##Design Philosophy

The website combines a minimalist luxury aesthetic with functional vehicle discovery. Its visual identity uses a predominantly black-and-white interface with red accents, bold typography, carefully structured vehicle cards, and interactive elements to create a premium automotive browsing experience.

The goal is to make exploring vehicles engaging, straightforward, and accessible across devices.
